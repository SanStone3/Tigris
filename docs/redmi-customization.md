# Redmi 定制：本机验证范围

基线：上游 `main` 的 `b10e4c422545c2bce9efb6111bbb6c755626858b`，正式版
[v2.0.22](https://github.com/lesnolie/Tigris/releases/tag/v2.0.22)。调查日期：2026-11-06。
本阶段未连接电视；Android 编译、纯 JVM mock 与网络探测不能替代遥控器及固件验收。

## 内容源

上游内置 B 站两个客户端、斗鱼和单个自定义 JSON 来源。用户当前电视已安装的优先对象是
**哔哩哔哩 TV、芒果 TV、酷喵 TV**。本机只核验候选 TV 包名；实际已安装版本待电视开机后读取。

| 优先 TV 应用 | 已核 TV 包名 | 当前结果 |
| --- | --- | --- |
| 哔哩哔哩 TV | `com.xiaodianshi.tv.yst`、`com.tutu.myblbl` | 保留公开 UGC 热门源，使用原始 `pic`，运行时跳过非 FullHD 封面 |
| 芒果 TV | `com.hunantv.market`、`com.starcor.mango` | 包名已补充；严格 FullHD 来源仍未取得，当前不合格图片回壁纸 |
| 酷喵 TV | `com.cibn.tv` | 官网编辑轮播 `hImg` 已实测 1920×1080，运行时严格筛选；不取竖图 `img` |

本轮标准为**图片原生至少 1920×1080、接近 16:9（比例误差≤0.01）**，不是视频自身的分辨率，
也不是给小图加放大参数。B站扩查30条公开热门原始封面，20条符合；前12条已有7条符合。
三张酷喵当前横图均为1920×1080。本轮保留UGC排序，不擅自换成番剧/电影库。

芒果公开精选当前6张原始图均为1500×844；加官方OSS的1920处理参数仍未得到更大原图。
进一步静态核验的TV发行包为`com.starcor.mango`，匿名TV导航成功，但新版影视频道返回空节目模块；
旧TV频道的2021年节目和867×500等图片不作为当前每日更新来源。**芒果未标为FullHD适配完成**，
也不据此断言平台不存在1920×1080素材；后续需结合电视实际安装版本继续核对。

运行时后台寻找首个合格图片，轮播跳过低清/缺图；整个来源无合格图时回壁纸。
不会把测试样本、片名或ID写死为推荐列表。当前图标持续获得焦点时，按15分钟缓存时效重新在线读取；
失焦、暂停、弹窗、销毁时停止，返回后再恢复。接口重取不保证平台运营必定更换内容。
关闭自动轮播时保留仍有效的当前节目。无账号Cookie、私人数据库或设备身份伪装。

FullHD候选单图最多5MiB，旧源及自定义图保持2MiB；解码最长边严格不超过1920且不放大小图。
缓存最多60张且总量≤120MiB，尺寸不合格结果短期记忆，避免反复下载同一张低清图。

爱奇艺、腾讯等既有适配代码保留，本轮不继续扩展。此前爱奇艺公开热榜原图已核1920×1080；
腾讯`ready_image_url`实测15条中4条原生1920×1080，但原`pic_1920x800`不算完整1080p。
用户明确不安装斗鱼，已排除本次配置与验收，未继续处理其图片或安装。

夸克核验的是官方TV包`com.quark.yun.tv` 2.9.1702，其最近播放输出和媒体库入口仍待真机确认。
用户选择使用TV媒体库自身刮削，不使用外部重命名工具；未改名、移动或删除任何网盘文件。
媒体库是否需要手机扫码，以电视实际页面为准，当前未完成电视端配置。

公开来源、TV包取证及图片测量摘要见`app/src/test/resources/shelf/sources.json`；
离线样本只用于测试，生产桌面不会从测试文件读取推荐内容。在Dock按确定仍然打开对应App，
不声称逐节目直达。MENU打开小米设置的既有绑定保持不变。

## 壁纸、网格和屏保

- 全部 App 网格取消全屏模糊遮罩，展开时 Dock 及其阴影退隐，壁纸仍可见。
- 壁纸首屏保留必应、我的照片、自定义、纯色与渐变；其他来源折叠，原设置键保留。
- 必应同一市场通常每天更新一张；`n=8` 等参数列出历史图片，不是每天八张。
  不同市场可能不同，UHD 地址也不保证每张都是 4K。本机抽样下载实际为 3840×2160。
- 画质变更使必应队列失效；日期/图片地址去重，UHD 失败回退，缓存标注实际保存尺寸。
  自动画质沿用内存预算；可在设置选择 4K 优先。
- 默认由电视系统管理屏保，关闭本分支相框计时和 PhotoDream 组件。
  只恢复已有记录且仍安装的原组件，不再猜测索尼组件；缺少记录时从系统设置选择。
- 参考 [Aerial](https://github.com/pengchujin/aerial-tv) 的简洁分类，保留 Tigris 的现有视觉与设置。

## 遥控交互与外观控制

- MENU 始终交给系统，保留用户已有的「菜单键 → 小米设置」绑定；控制中心使用上键或右上按钮。
- Back 按界面层级关闭弹窗/文件夹、退出整理、关闭控制中心、收回全部应用至 Dock。
  在 Dock 再按 Back 保持当前桌面，不反复弹出控制中心。
- 焦点以应用/文件夹标识及滚动锚点恢复；删除、重排和异步刷新后选择仍有效的相邻项。
  明确按 Home 回 Dock，外部应用/设置返回则恢复原位置。
- Dock 选中卡片放大、上浮并配阴影，全部应用页使用较小幅度。连续方向键缩短动画、
  抑制回弹并节流重复事件；保持 OK 长按整理。
- 性能三档为流畅、均衡、完整特效。预算独立于壁纸画质：流畅档暂用静态背景和简化材质，
  均衡档允许常规玻璃，完整档允许极致玻璃；切档保留原有素材与独立样式偏好。
- Top Shelf 支持逐应用推荐/壁纸、轮播开关、8/15/30/60 秒间隔。异步请求按代际校验，
  离开页面或改设置后，旧响应不会重新盖住壁纸。
- 主要外观与画质设置使用带当前勾选的选择列表；取消不保存。性能/焦点提供局部动画样例，
  确认后回到原设置行。恢复外观默认仅清除明确列出的外观与顶部内容展示设置。

## 4K 与安装身份

原生 4K 窗口下，App 卡片以 800×450 栅格化，替代原 400×225 中间图。
文字和布局继续按窗口密度渲染；设置分别显示实际 UI 窗口和面板输出尺寸。
低清 App 原图及网页海报不能变成真实 4K 素材。

[Android TV 官方文档](https://developer.android.com/training/tv/playback/memory)
明确区分 UI 与视频输出分辨率。4K 面板、4K 视频和 4K 壁纸都不能证明窗口是 4K。
本阶段不修改全系统 `wm size`、density 或显示模式，最终能力须真机核验。

官方版由上游私钥签名，本地测试 APK 无法直接覆盖。`standardDebug` 使用
`com.leslie.tvhome.redmi`、名称「Tigris 定制测试」，与原版并行保留；账户类型及
自更新身份同步隔离，更新来源改为个人 fork。尚未发布定制 Release。若 fork 仅发布原包名的 APK，测试包会拒绝该更新；
测试包目前通过本机构建更新，不保证在线自更新可用。
测试包不会继承原应用的私有设置；不得为迁移而直接卸载或清除原版数据。

## 验证与真机边界

本地检查：`testStandardDebugUnitTest testGuardDebugUnitTest assembleStandardDebug lintStandardDebug` 已通过；
Standard、Guard 各 51 个套件、275 项测试均通过，Lint 0 errors（66 warnings）。
APK 签名校验、包名、版本、中文名称和独立账户类型均已从最终 APK 读回核验。
新增 mock 覆盖公开来源真实响应的精简样本、广告过滤、重复/坏图片、结构变化、壁纸回退、
必应画质/缓存策略、系统屏保不被厂商超时抢占、已记录屏保恢复、1080p/4K 布局，
以及 MENU 委托、Back 层级、包名/滚动焦点、连按节流、放大边界、Shelf 代际、设置暂存，
芒果首页广告/节目过滤、腾讯既有大图/备用图选择、FullHD真尺寸筛选、失败候选扫描、
前台定时刷新、负缓存、磁盘预算及设置/控制中心往返的生命周期。
没有运行 Android 模拟器或验收真实遥控器交互。

提供电视 IP 后先读取型号/Android 版本、安装包与签名、原桌面/Guard/屏保状态、
UI/面板尺寸和内存；核对应用实际包名。并行测试前协调原版 Guard，避免两个桌面互抢。
随后验收内容海报、下键网格/返回焦点、系统屏保和图片清晰度。
实体 Home、待机唤醒及冷启动分别验证；不自动关机、重启、停用厂商桌面或全局改分辨率。

## 真机验收后的清理

本机阶段不连接电视。真机阶段记录传输/安装的临时路径，验收后清理已确认的安装包、
临时文件和不再需要的测试进程；同时排查之前的安装残留。旧应用须先识别用途和依赖。
用户提到的按键映射软件需结合包信息、无障碍服务及实际键绑定核对；
MENU 打开小米设置的能力必须保留。厂商桌面、系统设置、播放/输入源组件和用户成果保留。
